Công Thức Nguyên Hàm

Tổng hợp nhanh + ví dụ dễ hiểu

Công thức cơ bản

\( \int x^n dx = \frac{x^{n+1}}{n+1} + C \)
Ví dụ: \( \int x^2 dx = \frac{x^3}{3} + C \)
\( \int (u+v)dx = \int u dx + \int v dx \)
Ví dụ: \( \int (x + \sin x)dx = \frac{x^2}{2} - \cos x + C \)
\( \int (u-v)dx = \int u dx - \int v dx \)
Ví dụ: \( \int (e^x - 1)dx = e^x - x + C \)
\( \int kf(x)dx = k\int f(x)dx \)
Ví dụ: \( \int 5x^4 dx = 5 \int x^4 dx = 5 \cdot \frac{x^5}{5} + C = x^5 + C \)

Lượng giác

\( \int \sin x dx = -\cos x + C \)
Ví dụ: \( \int 2\sin x dx = -2\cos x + C \)
\( \int \cos x dx = \sin x + C \)
Ví dụ: \( \int \frac{1}{2}\cos x dx = \frac{1}{2}\sin x + C \)
\( \int \tan x dx = -\ln|\cos x| + C \)
Ví dụ: \( \int 3\tan x dx = -3\ln|\cos x| + C \)
\( \int \cot x dx = \ln|\sin x| + C \)
Ví dụ: \( \int 4\cot x dx = 4\ln|\sin x| + C \)

Hàm mũ & log

\( \int e^x dx = e^x + C \)
Ví dụ: \( \int 7e^x dx = 7e^x + C \)
\( \int \frac{1}{x} dx = \ln|x| + C \)
Ví dụ: \( \int \frac{3}{x} dx = 3\ln|x| + C \)
\( \int a^x dx = \frac{a^x}{\ln a} + C \)
Ví dụ: \( \int 3^x dx = \frac{3^x}{\ln 3} + C \)
\( \int \frac{1}{1+x^2} dx = \arctan x + C \)
Ví dụ: \( \int \frac{2}{1+x^2} dx = 2\arctan x + C \)
\( \int \frac{f'(x)}{f(x)} dx = \ln|f(x)| + C \)
Ví dụ: \( \int \frac{2x}{x^2+1} dx = \ln(x^2+1) + C \)

Nguyên hàm từng phần

\( \int u\,dv = uv - \int v\,du \)
Ý tưởng: Dùng khi tích của 2 hàm khác loại (đa thức × mũ / lượng giác)
Bước 1: Chọn \( u \)
Bước 2: Đặt phần còn lại là \( dv \)
Bước 3: Tính \( du, v \)
Bước 4: Thay vào công thức

Ví dụ: Tính \( \int x e^x dx \)

Bước 1 & 2: Chọn \( u = x \Rightarrow du = dx \). Phần còn lại \( dv = e^x dx \Rightarrow v = e^x \)
\( \int x e^x dx = x e^x - \int e^x dx \)
\( = x e^x - e^x + C \)
\( = e^x(x-1) + C \)
